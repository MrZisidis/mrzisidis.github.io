Pearson Edexcel Pseudocode Guide

The specific syntax required in written algorithms in Paper 1 and Paper 2.

Syntax Cheat Sheet

Variable Assignment
SET variable TO value

Example: SET count TO 0

Input / Output
SEND "message" TO USER RECEIVE variable FROM USER

Outputs text to user screen and captures variables input.

Selection (IF-THEN-ELSE)
IF count > 10 THEN
  SEND "High" TO USER
ELSE
  SEND "Low" TO USER
END IF
Conditional Iteration (WHILE-DO)
WHILE count < 5 DO
  SET count TO count + 1
END WHILE
